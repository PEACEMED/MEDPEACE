## ✦ About MEDPEACE

**MEDPEACE** is a modern digital platform designed with medical students in mind.

Medical school is demanding. Between lectures, practical sessions, attendance requirements, studying, and countless deadlines, staying organized can become a challenge.

MEDPEACE aims to make that experience simpler.

Instead of switching between multiple websites and applications, MEDPEACE brings useful academic tools into one clean, focused, and peaceful environment.

Our philosophy is simple:

> Less distraction. More focus. Better organization.

## ✨ Features

### 🧭 A Clean & Minimal Experience
- Modern, minimalist interface.
- Calm visual identity.
- Simple and intuitive navigation.
- Responsive design for different screen sizes.
- Focus on usability without unnecessary distractions.

### ⏱️ Study Tools
- **Penguin Stopwatch:** A dedicated stopwatch experience for tracking study sessions and managing time.
- A growing space for useful productivity tools.
- Designed to make everyday academic tasks easier.

### 🎓 Academic Organization
The platform is designed to grow into a more complete student experience, including:

- Personal student dashboards.
- Course organization.
- Lecture attendance checklists.
- Learning progress tracking.
- Course completion percentages.

### 🔐 Student Accounts & Management
Planned platform capabilities include:

- Individual student accounts.
- Personalized academic information.
- Student and administrator roles.
- Course and lecture management.

## 🎨 Design Philosophy

MEDPEACE isn't just about functionality. It's also about how technology feels.

The design follows three principles:

| Principle | Meaning |
|---|---|
| Simplicity | Keep the experience intuitive and uncluttered. |
| Clarity | Make important information easy to find. |
| Peace | Create a comfortable environment for focused work. |

Every element should have a purpose.

## 🚀 Getting Started

Want to explore the project locally?

### 1. Clone the repository

```bash
git clone https://github.com/PEACEMED/MEDPEACE.git
```

### 2. Navigate to the project

```bash
cd MEDPEACE
```

### 3. Open the project

Open `index.html` in your browser, or use the VS Code Live Server extension.

No complicated installation process is required for the current static frontend.
